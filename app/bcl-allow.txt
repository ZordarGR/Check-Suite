# Every type and member name rc-tbind.exe's metadata carries.
#
# The helper is compiled on Linux against Mono's class library and runs on
# Windows against .NET Framework 4.8, which is the smaller of the two. A name
# arriving here that does not exist there compiles cleanly and then kills the
# method that uses it on first call -- see build-check.py.
#
# So: adding a line to this file is the moment to confirm the member exists in
# .NET Framework 4.8. Nothing else in this build will tell you.
#
# Reviewed for 1.17.23 (v14). Regenerate deliberately, never wholesale.
#
# v12 added the read-only window scan. Everything it brought in is either our own
# identifier or a user32 P/Invoke name -- EnumChildWindows, GetDlgCtrlID, GetParent,
# GetWindowRect, IsWindowVisible, SendMessageTimeoutW -- and P/Invoke carries no BCL
# risk. NOTE: String.TrimEnd() was deliberately NOT used; mcs binds a parameterless
# overload that .NET Framework 4.8 may not have, and this guard cannot tell overloads
# apart. That is the same shape as the Split() call that once killed ParseBind.
#
# v10 added the Caps Lock window and the login entry. The framework surface that
# came with it, each confirmed present in .NET Framework 4.8 and not Mono-only:
#   Microsoft.Win32.Registry / RegistryKey / CurrentUser / OpenSubKey / CreateSubKey
#     / GetValue / SetValue / DeleteValue(string,bool) / Close   -- mscorlib
#   Process.GetProcessesByName / GetCurrentProcess / MainModule, ProcessModule.FileName,
#     ProcessStartInfo.UseShellExecute / CreateNoWindow, System.ComponentModel.Component
#   System.IO.File.ReadAllLines / GetLastWriteTimeUtc / Exists, DateTime.MinValue
#   Marshal.GetFunctionPointerForDelegate(Delegate) and Marshal.SizeOf(Type) -- the
#     NON-generic overloads, deliberately; the generic ones are newer.
#   IsVolatile -- the modreq the `volatile` field compiles to.
# Everything else v10 added is either our own identifier or a user32/gdi32 P/Invoke
# name, and P/Invoke carries no BCL risk at all -- which is exactly why the drawing
# is raw GDI instead of System.Drawing.
